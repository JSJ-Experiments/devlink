Permanent enable survives reboot. Timers keep their original deadline. Off stops the tunnel and DevLink SSH.

ADB

Reuses Box's loopback ADB when present. Otherwise temporarily adds a protected loopback listener. Wireless Debugging remains configured; an owned listener requires an adbd restart.

Transfer lanes

The host transfer helper manages these automatically. Extra lanes use separate WebSocket/TCP connections; they add keepalives while enabled.

Origin and subpath


Any hostname, IP, port and subpath work when they route to the same DevLink server. E.g. https://arm.jadenjsj.com/tools/devlink. Server --path and Caddy route must match. TLS certificates and the inner server fingerprint are verified.
